OFFLINE-FIRST

Catatan harian tetap dekat denganmu.

Database lokal menjadi fondasi pencatatan Uangii. Aktivitas utama—termasuk transaksi, Auto-Capture Notifikasi lokal, 7 Tools, dan analitik—tidak bergantung pada koneksi server.

  • Pencatatan atomik (withTransaction) dan pembacaan data lokal berjalan luring.
  • Perlindungan data mencakup enkripsi database, Android Keystore, dan kunci perangkat.
  • Cadangan terenkripsi ke file atau Google Drive membantu pemulihan jika perangkat rusak/hilang.
Perangkat Layanan cloud Perangkat ↔ layanan ↔ database pusat
CLOUD-CENTRIC / MODEL ILUSTRATIF

Layanan jarak jauh menjadi pusat data.

Pada pendekatan ini, data utama dikelola melalui server pusat. Ini mendukung akses lintas perangkat, dengan ketergantungan pada koneksi dan kebijakan penyedia.

  • Kebutuhan internet bergantung pada rancangan cache dan sinkronisasi.
  • Keamanan mencakup akun, perangkat, serta infrastruktur server penyedia.
  • Ketersediaan layanan jarak jauh menjadi bagian dari pengalaman harian.

CONNECTED WHEN IT MATTERS

Offline sebagai fondasi.
Koneksi dengan tujuan jelas.

Offline-first tidak berarti tertutup dari cloud. Berikut fitur opsional yang menggunakan koneksi internet ketika Anda memilihnya:

↥

Google Drive Backup

Pencadangan manual maupun berkala ke Google Drive pribadi dienkripsi AES-256-GCM sebelum diunggah dan memerlukan akun Google serta internet.

✦

Fio Gemini Cloud

Mode AI cloud & OCR struk cloud memerlukan internet. Mode Fio offline dan Auto-Capture Notifikasi tetap berjalan 100% lokal di perangkat.

◇

Ruang Keluarga & VIP

Sinkronisasi Ruang Keluarga antarperangkat serta verifikasi hak langganan Google Play / voucher memerlukan koneksi internet.
