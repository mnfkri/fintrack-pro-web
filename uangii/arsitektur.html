DIFFERENT MODELS. DIFFERENT TRADE-OFFS.

Dua pendekatan.
Pahami bedanya.

Pilih model untuk melihat pusat penyimpanan dan alur dasarnya. Diagram ini merupakan ilustrasi konsep, bukan pemantauan sistem secara langsung.

OFFLINE-FIRST

Catatan harian tetap dekat denganmu.

Database lokal menjadi fondasi pencatatan Uangii. Aktivitas utama tidak harus menunggu koneksi ke server untuk menyimpan transaksi.

  • Pencatatan dan pembacaan data lokal dapat berjalan luring.
  • Perlindungan data mencakup database dan keamanan perangkat.
  • Cadangan membantu menghadapi perangkat rusak atau hilang.
PerangkatLayanan cloudPerangkat ↔ layanan ↔ database
CLOUD-CENTRIC / MODEL ILUSTRATIF

Layanan jarak jauh menjadi pusat data.

Pada pendekatan ini, data utama dikelola melalui layanan server. Ini dapat mendukung akses lintas perangkat, dengan ketergantungan koneksi dan kebijakan penyedia.

  • Kebutuhan internet bergantung pada fitur cache dan sinkronisasi.
  • Keamanan mencakup akun, perangkat, dan layanan server.
  • Ketersediaan layanan menjadi bagian dari pengalaman pengguna.
