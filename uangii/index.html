Kepatuhan UU No. 27 Tahun 2022 (UU PDP)

Kebijakan Privasi Uangii

Terakhir diperbarui: 11 Oktober 2026 | Versi 2.0 (Arsitektur Offline-First & UU PDP)

Selamat datang di Uangii, aplikasi pencatat keuangan pribadi yang dikembangkan oleh Emtitra Production ("kami"). Kami sangat menghargai privasi dan hak atas perlindungan data pribadi Anda. Kebijakan Privasi ini disusun berdasarkan kepatuhan terhadap Undang-Undang Republik Indonesia Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP) dan regulasi terkait transaksi elektronik (UU ITE).

1 Prinsip Dasar & Arsitektur Offline-First

Uangii dibangun dengan filosofi Zero-Server Architecture (Offline-First):

  • Kami tidak memiliki server pusat yang mengumpulkan, memproses, atau menyimpan catatan transaksi keuangan, besaran saldo, atau data anggaran Anda.
  • Seluruh basis data transaksi Anda disimpan secara lokal di media penyimpanan perangkat seluler Anda sendiri dan dilindungi dengan enkripsi SQLCipher (AES-256).
  • Kami tidak memonetisasi, menjual, memperdagangkan, atau membagikan data keuangan pribadi Anda kepada pihak ketiga mana pun untuk tujuan periklanan atau pemrofilan kredit.

2 Data yang Diproses pada Perangkat Anda

Saat Anda menggunakan Uangii, data berikut hanya diproses dan disimpan secara lokal di perangkat Anda:

  • Catatan Finansial: Nominal transaksi, kategori pemasukan/pengeluaran, tanggal, catatan opsional, dan data aset investasi yang Anda masukkan secara sukarela.
  • Pengaturan Aplikasi: Preferensi mata uang, tema tampilan, dan kunci sandi/PIN lokal.

3 Layanan Pihak Ketiga & Integrasi Eksternal

Aplikasi ini dapat berinteraksi dengan layanan pihak ketiga hanya atas persetujuan dan inisiasi aktif Anda:

  • Google Drive API (Pencadangan Mandiri): Jika Anda mengaktifkan fitur cadangan, file basis data terenkripsi akan diunggah langsung dari perangkat Anda ke ruang Google Drive milik akun Google Anda sendiri. Token otorisasi disimpan secara aman di perangkat dan tidak pernah dikirim ke pihak Emtitra Production.
  • Google Play Services: Digunakan untuk pembaruan aplikasi dan analitik diagnostik kerusakan aplikasi (crash reporting) yang bersifat anonim tanpa data identitas finansial.
  • Asisten AI (Fio): Permintaan konsultasi yang dikirimkan ke model kecerdasan buatan hanya berisi teks prompt umum tanpa menyertakan identitas pribadi atau rekening asli Anda.

4 Hak Subjek Data Berdasarkan UU PDP

Sesuai Pasal 5 hingga Pasal 13 UU No. 27 Tahun 2022, sebagai pemilik data pribadi Anda berhak untuk:

  • Mengakses & Memperoleh Salinan Data: Anda dapat mengekspor seluruh catatan transaksi dalam format dokumen PDF atau cadangan database kapan pun.
  • Memperbaiki Data (Hak Koreksi): Anda memiliki kendali penuh untuk menyunting setiap data transaksi yang keliru langsung dari aplikasi.
  • Menghapus Data (Hak Pemusnahan): Anda dapat menghapus seluruh transaksi atau mereset aplikasi kapan saja. Menghapus aplikasi dari ponsel Anda akan melenyapkan seluruh basis data lokal secara permanen.

5 Keamanan Data Kriptografis

Kami menerapkan prinsip Privacy by Design dan Privacy by Default dengan menerapkan teknologi enkripsi basis data SQLCipher 256-bit untuk memastikan data Anda aman bahkan jika perangkat ponsel Anda berpindah tangan tanpa izin.

Analisis Arsitektur Sistem

Arsitektur Cloud Konvensional vs Offline-First Uangii 🛡️

Mengapa model penyimpanan lokal adalah masa depan privasi finansial pribadi.

Dalam era digital di mana kebocoran data (*data breaches*) marak terjadi, cara sebuah aplikasi menyimpan nominal uang dan transaksi Anda adalah hal yang paling krusial. Uangii menolak model sentralisasi cloud konvensional.

⚠️

Cloud Konvensional (Honeypot)

Data jutaan pengguna berkumpul di satu server terpusat. Sekali server tertembus, seluruh riwayat belanja dan saldo pengguna terekspos.

Status: Risiko Terpusat & Ketergantungan Kuota
🛡️

Uangii Zero-Server Architecture

Data tersimpan 100% lokal di folder privat Android terlindungi Linux sandbox. Tidak ada server terpusat yang bisa diretas atau bocor.

Status: Zero Point of Failure & 100% Luring

1 Titik Kerentanan Cloud Database (Single Point of Failure)

Pada aplikasi cloud tradisional:

  • Data jutaan pengguna disimpan dalam satu klaster server terpusat. Ini menjadikannya target bernilai tinggi bagi peretas (*honeypot*).
  • Data riwayat belanja sering kali diproses oleh algoritma analitik pihak ketiga untuk penargetan iklan atau penawaran kredit konsumtif.

2 Keunggulan Zero-Server Architecture Uangii

Dengan filosofi Zero-Knowledge & Zero-Server:

  • Tidak Ada Server Pusat: Kami sengaja tidak membangun database yang menyimpan riwayat belanja Anda. Apa yang tidak kami miliki, mustahil bisa bocor dari pihak kami.
  • Penyimpanan Terisolasi (Sandboxed Storage): Basis data berada dalam folder privat aplikasi di dalam sistem operasi Android Anda yang dilindungi oleh Linux kernel permission.

1 Enkripsi Database SQLCipher (AES-256)

Basis data SQLite lokal dienkripsi secara penuh (*full database encryption*):

  • Algoritma AES-256: Standar enkripsi simetris yang diadopsi oleh lembaga perbankan global dan militer untuk melindungi data rahasia tinggi.
  • Enkripsi Page-by-Page: Setiap halaman (*page*) data dienkripsi sebelum ditulis ke media penyimpanan fisik. File database yang disalin secara ilegal melalui sambungan kabel USB ke komputer hanya akan berupa deretan biner tak terbaca.
  • Derivasi Kunci PBKDF2: Kunci enkripsi diproteksi dengan fungsi derivasi ribuan iterasi untuk menangkal serangan brute-force atau dictionary attacks.

2 Kepatuhan Terhadap UU PDP Indonesia (UU No. 27 Tahun 2022)

Prinsip Pelindungan Data Pribadi diterapkan secara by design:

  • Hak Akses & Portabilitas: Pengguna berhak mengekspor data dalam format PDF atau basis data cadangan kapan saja tanpa dipersulit.
  • Hak Penghapusan Permanen: Menghapus catatan transaksi atau meng-uninstall aplikasi secara otomatis melenyapkan data lokal tanpa jejak tersisa di pihak kami.
  • Prinsip Minimalisasi Data: Aplikasi hanya meminta izin perangkat yang mutlak dibutuhkan (misal: izin penyimpanan untuk ekspor PDF).

3 Perlindungan Aplikasi & Sandi Biometrik

Lapisan proteksi fisik perangkat:

  • Mendukung proteksi PIN lokal dan autentikasi biometrik (sidik jari / fingerprint) sebelum dasbor finansial dapat dibuka.
  • Mencegah orang lain yang sedang meminjam ponsel Anda melihat rincian saldo dan transaksi pribadi Anda.
