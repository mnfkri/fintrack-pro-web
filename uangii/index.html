Pertanyaan yang sering diajukan 💬

Apakah data keuangan saya dikirim ke server Uangii?

Sama sekali tidak. Uangii tidak memiliki server database untuk menampung riwayat Anda. Semua data disimpan lokal dan terenkripsi. Satu-satunya salinan cadangan adalah file yang Anda putuskan sendiri untuk di-backup ke Google Drive pribadi Anda.

Apakah Uangii bisa digunakan tanpa koneksi internet?

Tentu saja! Pencatatan uang keluar/masuk, dasbor, dan laporan bekerja 100% offline. Internet hanya dibutuhkan saat Anda menyinkronkan cadangan ke Google Drive atau menggunakan asisten AI.

Apakah Uangii bisa mengintip file lain di Google Drive saya?

Tidak bisa. Uangii hanya memohon izin terbatas (drive.file / drive.appdata) yang hanya mengizinkan aplikasi membuka atau mengelola file cadangan yang dibuatnya sendiri.

Apakah saran AI di Uangii adalah anjuran investasi resmi?

Bukan. Seluruh saran AI ditujukan sebagai bahan edukasi dan wawasan keuangan pribadi, bukan nasihat penasihat keuangan bersertifikat OJK.

Bagaimana jika saya ganti HP?

Cukup gunakan fitur Backup ke Google Drive di perangkat lama, lalu unduh Uangii di perangkat baru dan pilih Pulihkan Data dengan akun Google yang sama.

Kebijakan Privasi (Privacy Policy) 🔒

Terakhir diperbarui: 10 Oktober 2026 • Versi 2.0

Selamat datang di Uangii ("Aplikasi", "Kami"), produk perangkat lunak yang dikembangkan oleh Emtitra Production. Kami menghargai dan berkomitmen penuh untuk melindungi data pribadi pengguna sesuai dengan Undang-Undang Republik Indonesia No. 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP) serta UU Informasi dan Transaksi Elektronik (UU ITE).

1Prinsip Desain Offline-First & Lokalisasi Data

Uangii dirancang dengan arsitektur Privacy by Design dan Offline-First. Seluruh catatan transaksi, saldo dompet, pos anggaran, target tabungan, dan catatan hutang-piutang Anda disimpan secara eksklusif pada media penyimpanan internal perangkat Anda dalam basis data lokal terenkripsi (SQLCipher / Room). Kami tidak mengoperasikan server eksternal perantara untuk menyimpan, memproses, memonetisasi, atau menjual riwayat keuangan Anda.

2Izin Notifikasi Transaksi (Notification Listener)

Aplikasi menyediakan fitur opsional untuk mendeteksi pesan mutasi perbankan atau dompet digital (e-wallet). Pemindaian teks notifikasi dilakukan 100% di perangkat (on-device processing) tanpa transmisi jaringan. Izin ini hanya digunakan secara spesifik untuk mengenali nominal, jenis transaksi, dan nama merchant guna mempermudah pencatatan otomatis.

3Pemrosesan Asisten Cerdas (Fio AI)

Saat Anda berkonsultasi atau mencatat secara interaktif dengan Fio AI, kueri kontekstual diproses melalui API model kecerdasan buatan (Google Gemini API). Data yang dikirimkan hanyalah teks pertanyaan atau ringkasan nominal tanpa nama lengkap, nomor rekening, PIN, atau data kredensial rahasia. Data tersebut tidak digunakan untuk pelatihan model publik. Jika perangkat dalam kondisi luring (offline), Fio AI secara otomatis beralih ke logika analitik lokal di perangkat.

4Pencadangan Google Drive (Cloud Backup)

Aplikasi menyediakan fitur opsional untuk mencadangkan data ke Google Drive pribadi Anda. Dalam fitur ini:

  • Aplikasi hanya meminta cakupan akses terbatas (drive.appdata / drive.file) ke direktori privat khusus aplikasi Uangii.
  • Aplikasi tidak dapat mengakses, membaca, mengubah, atau menghapus berkas lain di Google Drive Anda.
  • Kredensial akun Google Anda dikelola langsung oleh sistem Google Play Services dan tidak pernah disimpan oleh Emtitra Production.

5Hak Subjek Data (Sesuai UU PDP Bab VI)

Sebagai pemilik data pribadi, Anda memiliki kendali penuh:

  • Hak Akses & Portabilitas: Anda dapat mengekspor seluruh catatan keuangan Anda kapan saja ke format CSV, Excel, atau JSON cadangan lokal.
  • Hak Koreksi & Penghapusan: Anda dapat mengedit atau menghapus sebagian maupun seluruh database secara permanen melalui menu Pengaturan di dalam aplikasi.
  • Hak Menarik Persetujuan: Anda dapat menonaktifkan fitur AI, backup Google Drive, atau izin pembaca notifikasi kapan pun melalui pengaturan perangkat.

6Keamanan & Autentikasi Biometrik

Fitur Kunci Aplikasi mendukung perlindungan PIN lokal dan autentikasi biometrik (sidik jari / pemindai wajah). Autentikasi biometrik diproses langsung oleh modul keamanan perangkat keras Android melalui API BiometricPrompt resmi. Data sidik jari dan wajah Anda tidak pernah dapat diakses atau disimpan oleh Uangii.
