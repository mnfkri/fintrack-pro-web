Tanya Jawab

Pertanyaan yang sering diajukan 💬

Apakah data keuangan saya dikirim ke server Uangii?

Sama sekali tidak. Uangii tidak memiliki server database untuk menampung riwayat Anda. Semua data disimpan lokal dan terenkripsi. Satu-satunya salinan cadangan adalah file yang Anda putuskan sendiri untuk di-backup ke Google Drive pribadi Anda.

Apakah Uangii bisa digunakan tanpa koneksi internet?

Tentu saja! Pencatatan uang keluar/masuk, dasbor, dan laporan bekerja 100% offline. Internet hanya dibutuhkan saat Anda menyinkronkan cadangan ke Google Drive atau menggunakan asisten AI.

Apakah Uangii bisa mengintip file lain di Google Drive saya?

Tidak bisa. Uangii hanya memohon izin terbatas (drive.file / drive.appdata) yang hanya mengizinkan aplikasi membuka atau mengelola file cadangan yang dibuatnya sendiri.

Apakah saran AI di Uangii adalah anjuran investasi resmi?

Bukan. Seluruh saran AI ditujukan sebagai bahan edukasi dan wawasan keuangan pribadi, bukan nasihat penasihat keuangan bersertifikat.

Bagaimana jika saya ganti HP?

Cukup gunakan fitur Backup ke Google Drive di perangkat lama, lalu unduh Uangii di perangkat baru dan pilih Pulihkan Data dengan akun Google yang sama.

Waktunya bikin keuanganmu lebih wangi & tertata 💸🌸

Kebijakan Privasi (Privacy Policy) 🔒

Terakhir diperbarui: Oktober 2026

Uangii ("Aplikasi", "kami") berkomitmen penuh untuk menjaga kebersihan dan keamanan privasi data Anda. Kebijakan ini menjabarkan bagaimana data Anda diproses di dalam Aplikasi.

1Penyimpanan Data Lokal & Arsitektur Offline-First

Uangii dibangun dengan prinsip offline-first. Seluruh data transaksi, kategori belanja, dompet, dan portofolio Anda tersimpan langsung pada ruang penyimpanan lokal perangkat Anda dalam database yang diamankan enkripsi kuat (SQLCipher). Kami tidak memiliki server eksternal untuk menyimpan, membaca, maupun memonetisasi catatan finansial Anda.

2Pencadangan Google Drive & Layanan Pihak Ketiga

Aplikasi menyediakan fitur opsional untuk mencadangkan data ke Google Drive pribadi Anda. Dalam implementasinya:

  • Aplikasi hanya meminta izin untuk membuat dan mengakses file cadangan miliknya sendiri (drive.file atau drive.appdata).
  • Aplikasi tidak akan pernah membaca, mengubah, menyalin, atau menghapus file lain di Google Drive Anda.
  • Kredensial akun Google dikelola langsung oleh sistem Google Play Services dan tidak pernah melewati server pengembang.

3Fitur Kecerdasan Buatan (AI Advisor)

Uangii menyediakan asisten finansial edukatif. Data ringkasan yang dikirimkan ke model AI hanya diproses secara temporer ketika Anda meminta evaluasi/tips, dan tidak dijadikan basis pelatihan model publik.
