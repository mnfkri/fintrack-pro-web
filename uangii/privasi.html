ENCRYPTION, WITH CONTEXT

Bedakan tempat data berada.
Pahami perlindungannya.

Enkripsi database dan enkripsi cadangan melindungi data pada konteks yang berbeda.

▦

Database lokal

SQLCipher melindungi database lokal menggunakan enkripsi AES-256. Catatan tersimpan dalam basis data aplikasi di perangkat.

↥

Cadangan terenkripsi

Data cadangan dienkripsi sebelum diunggah ke Google Drive. Proses pencadangan menggunakan AES-256-GCM dengan derivasi kunci PBKDF2.

✦

Konteks untuk Fio

Penyamaran informasi identitas membantu mengurangi paparan data pribadi pada teks konteks. Pilihan mode AI menentukan apakah layanan cloud digunakan.

Enkripsi tidak menggantikan penguncian perangkat dan pengelolaan akses akun. Lindungi perangkat serta akun cadangan yang kamu gunakan.
